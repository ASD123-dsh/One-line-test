## 建议用户重点测试

1. 使用上述唯一 EXE，标题应显示 V1.58.3。首次未启用配置记忆时仍为 500ms；
   分别测试 500ms 和 10ms，循环中修改运行数据，确认后续帧和校验动态变化。
2. 持续发送时拖动窗口、编辑数据、停止/断开，以及包组循环顺序、统计和积压提示。
   统计是软件写入结果，10ms 设置不等于保证物理层达到硬实时 10ms 周期。
3. 右上角“配置 / 诊断”：配置导出、断开后导入、可选记忆开关及重启恢复；
   确认导入或恢复不会自动连接/发送。诊断不应包含授权、设备码、客户路径或原始日志。
4. 切换原有协议、预设和自定义帧，检查与旧版功能一致。中断事务恢复提示仅在
   隔离测试副本验证，不要在正在使用的目录构造损坏锁或删除事务材料。

该测试器，也未替换其基线或缓存；不能用它们代替 V1.58.3 新功能验收。
