候选和固定位置程序分别使用独占空 `APPDATA` / `LOCALAPPDATA` / 临时目录，在
offscreen 模式启动。实际激活界面进入事件循环后返回就绪确认，分别约 1.375 秒和
1.359 秒就绪，均继续稳定运行五秒，没有错误日志；只停止本轮自己创建的检查进程。
检查不读取客户已有授权，不使用签名私钥、不生成客户激活码，也不自动连接串口。

独立更新器只执行 `--help` 并返回 0，未创建安装任务、联网或执行真实跨版本升级。
Qt 输入法事件回归不能替代真实 Windows 输入法 Shift 切换和候选窗交互；本包供用户
实机验证，不能将打包或启动成功当作“Shift 问题已彻底解决”。

建议在新版搜索框中测试：Shift 中英文切换、中文候选确认/取消，输入 `rui` / `rl`
