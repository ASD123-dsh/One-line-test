## 需求与实现

按用户要求，将原问号菜单中的“检测更新”“扫码反馈”并入现有“配置 / 诊断”菜单。
沿用 Python / PyQt5，不新增依赖、不改变版本号，只调整菜单入口。

右上角只保留一个“配置 / 诊断”按钮，内容按以下三组排列：

1. 导入配置、导出配置、记住本机配置（默认关闭）。
2. 导出脱敏诊断、查看升级恢复指引。
3. 检测更新、扫码反馈。

组间使用分隔线。更新和反馈动作继续调用原 `show_update_dialog()` 与
`show_feedback_dialog()`，不改变后台检测下载、用户确认升级、恢复阻断或二维码页面。
配置仍默认不记忆、不自动连接、不自动发送，取消文件选择不改变当前状态。

移除重复的问号按钮及仅用于该按钮的样式和导入。旧 `feedback_btn`、`help_menu`
引用名称保留为统一按钮和菜单的别名，现有更新/反馈动作属性名称也不变。
没有增加自动联网检查或修改协议、串口发送、安装回滚及授权逻辑。
