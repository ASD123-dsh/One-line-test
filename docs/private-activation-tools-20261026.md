# 激活码生成工具仅保留本地

## 范围与原因

用户要求从 GitHub 仓库移除 `tools/activation_tool.py` 和
`tools/generate_activation_code.py`，保留本地原文件并防止后续再次上传，同时保证
软件正常激活、检测更新与升级不受影响。本次不编译、不打包、不升级版本号，不修改 Release。

两个工具通过 `git rm --cached -- <明确路径>` 取消跟踪，不从本地磁盘删除；
`.gitignore` 增加两个精确路径，`AGENTS.md` 禁止强制添加或复制改名上传。
`tools/check_project.py --require-tracked` 对本地私有路径不再报源码遗漏，但若路径
被重新跟踪则直接失败；其他源码的遗漏检查保持不变，本地工具仍会做语法检查。

此前激活测试在模块导入阶段直接依赖图形工具，现在仅在生成工具的文本导出用例内
延迟导入；公开检出缺少该工具时只跳过这一项。异常仅识别目标模块确实缺失的情况，
不吞掉工具自身的导入错误，其他激活、有效期、授权持久化和更新回归继续执行。
