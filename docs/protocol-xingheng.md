# 星恒智能BMS软件接入

## 日期、问题与原因

2026-11-10：客户仪表实际使用0x3A，参考截图确认31字节、版本13、len=1B、SOC位于索引3，
完整参考帧的前30字节累加和低8位为89。依据本地《智能BMS一线通协议说明A1.3.3（正式).pdf》
表A.2/A.5及客户截图实现，不上传PDF或客户图片。

- 仅接入软件：默认0x3A实时31字节，可在“数据自定义→电池数据→报文类型”选择0x01公有20字节。
- SOC为0.5%/bit，C8表示100%；电压0.1V，电流0.1A并带-500A偏移，温度带-40℃偏移，多字节小端。
- BMS状态、key和两个结果字节只原样编辑/透传；不解码、不随机更新、不生成密文，不承诺接收端验密通过。
- 保留单次、动态单帧循环、当前类型包组、全部自定义及配置恢复；两类型包组可同时保存，按当前类型编辑/发送。
- 普通数据变化供后续周期读取，类型变化先停发；新协议默认1000ms、测试范围10～5000ms，其他协议不变。
- 原始帧只检查字节及选定长度，允许故意错误的ID、len、校验和FF/FFFF无效值；不擅自修正回放字节。
