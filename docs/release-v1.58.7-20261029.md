# V1.58.7 发布与归档

## 用户授权与范围

用户明确要求提交协议列表鼠标切换和参数页闪窗修复、合并 main、打包发布 V1.58.7，
更新说明每项一句，发布成功后归档并清理。本轮仅将集中版本从 1.58.6 升至 1.58.7，
保留已核验的两项最小修复、原有布局、配色、协议编码、循环发送、输入法、授权及更新逻辑。
不实施字节加密开关，不修改新思维或其他协议算法。

## 两项修复

- 协议搜索的外部鼠标判断只处理 QWidget，避免 QWindow 先行事件误收起结果列表。
- 参数标题创建时就指定原参数页为父控件，避免先显示成独立窗口再进入布局。

根因与回归分别见 [鼠标选择说明](protocol-selector-mouse-20261029.md) 和
[闪窗说明](ui-protocol-switch-flash-20261029.md)。本地 V1.58.6 阶段文档保留原摘要和
“未发布”历史，本次正式发布事实不反写进过去的打包记录。
