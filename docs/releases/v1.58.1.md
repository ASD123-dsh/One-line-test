# V1.58.1：更新器目录占用修复

本版本将已经通过用户实际升级验证的更新器修复纳入完整正式包。
不修改原有协议帧、串口发送接口、发送间隔范围、扫码反馈和授权规则。

## 关键修复

- Windows 目录改名遇到错误码 5、32、33 时有限重试，每次最多 80 次、间隔 250ms，
  等待上限约 20 秒；旧版备份、安装替换和失败回滚共用此机制。
- 其他错误直接停止，不删除或覆盖冲突目录，不强制结束其他用户进程。
- 安装失败保留原始系统原因、失败阶段、Windows 错误码、重试次数、错误码序列、
  耗时、工作目录和完整异常链，避免日志只有“旧版本已恢复”的概括提示。
- 保留旧版目录备份、用户导出文件和原有授权数据路径。

## 升级方式与旧版限制

支持更新的版本可点击 `? → 检测更新`，下载并校验后确认“升级并重启”。
升级前请导出需要保留的包组，并关闭同一安装目录的其他工具实例。

**首次升级限制：安装动作由当前版本自带的更新器执行。**
原 V1.57/V1.58 的更新器不会因为下载了新包就自动获得修复。如果从旧版升级时仍
遇到目录替换失败，可以先手动解压完整 V1.58.1 包到一个新的独立目录使用，或先
应用本地更新器修复后再检测升级。不要只替换主 EXE。
安装 V1.58.1 后，后续升级会使用本版本自带的修复更新器。

完整附件：`AD-OneLine-v1.58.1-windows-x64.zip`。

## 验证范围

- 更新器修复对应的 183 项回归测试，包括临时占用、持续占用、回滚、路径冲突和日志。
- D 盘独占副本内的真实 Windows 目录锁测试，覆盖占用释放后继续安装及持续占用回滚。
- 用户确认本地修复后原路径升级成功。
- 本版本发布前重新构建主程序和独立更新器，验证完整包、归档模块及实际 EXE 启动。

真实硬件串口功能和不同用户的网络、目录权限仍需各自实测。
