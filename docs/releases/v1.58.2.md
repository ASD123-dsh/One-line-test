# V1.58.2 - 混放目录安全升级与备份自动清理

发布日期：2026-10-15。Windows x64，继续使用完整程序目录和 ZIP 分发，不改为单 EXE。
用户已确认混放目录升级、升级失败回滚及成功后自动清理备份均测试正常。
本次沿用已测试通过的安装包，不重新编译。

## 更新内容

- 使用专属运行库目录 `_ad_oneline_internal/` 和专属文件清单
  `ad-oneline-update-manifest.json`，避免与其他软件的共享 `_internal/` 冲突。
- 按清单逐文件更新、备份和回滚，不再重命名或整体替换安装目录。只备份本工具
  发生变化的文件，不搬动、备份或删除同级其他软件、用户文档和旧共享运行库。
- 新版界面完成启动确认并稳定运行 5 秒后，自动清理本次旧版备份及事务目录。
  替换或启动失败时恢复旧版；恢复未完成时保留备份、记录及锁，避免继续覆盖。
- 新路径与未知文件冲突、旧自有文件被修改、目录链接或并行更新等情况会停止安装，
  不猜测文件归属。Windows 临时文件占用有限重试，失败记录保留原系统原因。
- 清理受阻只记录警告，不把已经成功的升级误报为失败；不会批量删除历史备份。
- 增加本地跨版本验收入口、回归覆盖和项目产物收尾规则。构建脚本不再留下重复的
  过渡版可运行目录。原协议编码、串口、授权规则、对外接口和 UI 布局保持不变。

## 下载和首次迁移（重要）

推荐新安装和手动分发使用 **`AD-OneLine-v1.58.2-windows-x64-managed.zip`**。
完整保留主 EXE、专属运行库和专属清单，不能只复制一个 EXE。

**已混放其他软件的 V1.58.1 或更早客户端，首次请手动完整安装 managed 主包。**
旧版本安装器仍会执行整目录更新，下载新版不会提前修复旧安装器自身；不能直接
用旧安装器在混放目录尝试升级。手动迁移前关闭本工具，保留其他软件和原共享
`_internal/`，不要为了“清理旧文件”将其删除。采用专属布局后，后续更新可安全
按本工具清单执行。

原本安装在本工具独立目录中的旧客户端，可通过“检测更新”获取不带 `managed`
的旧格式过渡 ZIP，先升级到 V1.58.2。过渡包同样包含新版更新器，之后的升级会
优先选择 managed 主包；首次旧安装器可能仍保留一次整目录备份。
新客户端只接受受校验的专属布局进行逐文件安装，不向共享布局降级覆盖。
