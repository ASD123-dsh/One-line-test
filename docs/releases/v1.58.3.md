# V1.58.3 — 协议组件优化、后台发送与统一工具菜单

## 更新内容

- 将协议编码、参数校验、字节说明和预设拆分为独立组件，协议专用界面同步解耦，
  便于后续扩展；保留现有 18 种协议和原公开接口，不改变已定义帧头。
- 主界面串口写入改为单任务后台执行，循环中仍读取最新数据；加入缓冲积压限流、
  写入统计和时序提示，避免慢串口导致界面阻塞或旧任务无界积压。
- 配置导入/导出、可选本机记忆和脱敏诊断。记忆默认关闭，不自动连接或发送；
  配置与日志使用用户专属目录，不影响混放安装目录的其他应用。
- 普通打包版启动只读识别本工具未完成的更新事务，提供恢复指引，保留现场；
  不自动删除锁、清理未知材料或擅自回滚。
- 右上角统一为“配置 / 诊断”菜单，分组提供配置管理、诊断/恢复、检测更新和
  扫码反馈，移除独立问号按钮。检测下载、用户确认升级及原二维码页面流程保持不变。
- 固定已验证的依赖基线，并加入只做源码检查与回归测试的 Windows CI。

## 使用与兼容性

- 默认发送间隔仍为 500ms，可按协议设置更小的发送间隔；普通模式最低 10ms，
  原直接 BREAK 模式仍遵守其限制。软件写入周期和理论线速不代表硬件实测波形，
  10ms 不是硬实时保证，需结合串口波特率、转码平台和目标协议实际验证。
- 配置导入前先停止发送并断开串口；导入或恢复配置不会自动连接或开始发送。
- 保留按清单逐文件升级、混放目录保护、升级失败回滚和成功后清理自有备份。
  更新中断识别只提供恢复指引，不宣传为断电后自动恢复保证。
- V1.58.1 及更早的旧更新器仍有原整目录迁移限制，混放目录请先手动使用一次
  完整 managed 主包。下载新包不会提前替换正在执行安装的旧更新器。
