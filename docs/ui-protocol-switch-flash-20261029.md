## 根因与最小修复

原 `ProtocolTabs.addTab` 先创建无父控件的标题 `QFrame()`，再设置可见，最后才放入
参数页布局。每个 Status 页的标题因此先作为顶层窗口显示，再因重新设置父控件隐藏，
看起来一闪而过。事件跟踪已捕捉到标题及其原生窗口显示、隐藏；不是协议或升级报错。

生产代码仅改为 `QFrame(wrapper)`，创建时即属于原参数页，再执行原有可见性和布局
逻辑。保留标题内容、编辑说明、Status 页显示规则、非 Status 页隐藏规则及预设只读。
