继续使用原 Python/PyQt5，不新增依赖，不采用 DWM 模糊、自绘系统标题栏或动画。
参考图的玻璃观感由静态渐变、浅色卡片和细边框近似，原应用 ICO 与系统窗口操作保留。
不复制参考图演示版本 V1.58.4、示例帧数或虚构写入周期；本包显示 V1.58.5 和真实软件统计。

原始帧说明没有删除：表格右键“查看原始说明”，原格式页右键“返回字节表格”。
普通协议详细说明也保留在各字节悬停提示中，`current_frame_text` 仍指向原格式只读文本。
锂神 `F6` 的无符号十进制仍是 246，只在含义列显示 -10℃，不改变任何原始字节或校验。

历史表格使用 `QAbstractTableModel` 按批次增量插入，不逐帧重建整表，不新增线程或计时器。
原 100ms 刷新、超过 50 条立即刷新、10000 条上限、错误即时显示和自动滚动开关继续生效。
隐藏的原有界只读文本保留相同日志接口，提示和错误不会被显示为成功写入。
清空时同时清理待显示批次和两种视图，但不停止发送或删除磁盘用户日志。
