## 简短更新说明

- 优化柔和雾面配色、细边框与卡片布局。
- 增加协议名称搜索和可浏览的只读预设参数页。

- 改善小窗口滚动、数值显示和预览区域的空间分配。

## 实现与兼容性

继续使用 Python/PyQt5，未增加依赖，未调用 Windows 毛玻璃或透明窗口接口。
所谓雾面是 Qt 渐变背景、半透明白卡片和低亮度青绿色的视觉效果；保留系统标题栏、
原图标及现有菜单，不实现背景实时模糊，不增加动画或周期性界面刷新计时器。

- 串口配置压缩为三行，原串口、波特率、Tosc、连接信号及范围不变。
- “帧配置”收纳到协议行，原始帧编辑和包组入口仍保留。
- “协议参数”取代旧“Status位配置”标题，各协议原字段、名称、量程及读写入口不变。
- 参数页逐页滚动；预设只禁用内容，保留页签浏览和滚动，保留位原有禁用状态不被解除。
- 协议搜索输入只过滤弹层，不改变协议；明确选中合法结果才调用原协议切换入口。
  无结果、取消、搜索期间都不停止普通循环，真正切换协议仍按原逻辑停止旧循环。
- 表格和原始说明只显示已有字节快照，不再次编码、不消耗序号、不直接编辑或发送。
  相同快照不重建表格；仅更新变化项，淡黄色表示与上次同协议预览不同，不等于已写入硬件。
- 默认 1200×800，左侧无需整栏滚动且瑞轮十二字节完整可见；1000×640 小窗口采用
  左栏滚动和帧表滚动，避免压扁输入区域。上下监控区可拖动，用户拖动后保留分配比例。
- 增大旧数值控件的必要宽度，避免负号或末位被箭头遮挡；页签统一字重，修复 Qt 5
  缩放渲染下选中页签首字裁切。
- 保留原有有界发送历史、100ms 批量追加、后台发送快照、限流和线程边界。
  未修改协议编码、串口实现、升级事务、授权逻辑、构建脚本或公开接口。
